## Immediate Observations

- The subtitle is the highest-risk metadata item because it says `Track Streaming Movies & Shows` without saying the app tracks where content is available.
- The description is defensible, but should be tightened because it uses `streaming options` in the first and only sentence.
- Keywords are search-only metadata, but Apple still treats keywords as metadata. Safer keywords should avoid both `Stream` and `Streaming` if the next submission is meant to eliminate ambiguity.
- Review notes should be replaced with a fuller explanation of app behavior, no playback/download functionality, provider-link behavior, and the metadata changes made in response to the rejection.
